## 3. 核心组件设计

### 3.1 LLMEngine

**职责**：推理引擎的入口，协调各组件完成推理任务。

```
┌─────────────────────────────────────────────────────────────────┐
│                         LLMEngine                               │
├─────────────────────────────────────────────────────────────────┤
│  属性:                                                          │
│  ├── model_runner: ModelRunner    # 模型运行器                  │
│  ├── scheduler: Scheduler         # 调度器                      │
│  ├── tokenizer: AutoTokenizer     # 分词器                      │
│  └── ps: list[Process]            # 张量并行进程                 │
├─────────────────────────────────────────────────────────────────┤
│  方法:                                                          │
│  ├── __init__(model, **kwargs)    # 初始化引擎                   │
│  ├── add_request(prompt, params)  # 添加请求                     │
│  ├── step()                       # 执行一步推理                 │
│  ├── is_finished()                # 检查是否完成                 │
│  └── generate(prompts, params)    # 批量生成                     │
└─────────────────────────────────────────────────────────────────┘
```

**工作流程**：

```
generate() 调用
      │
      ├── for each prompt: add_request()
      │
      └── while not is_finished():
            │
            ├── step()
            │     ├── scheduler.schedule() → seqs, is_prefill
            │     ├── model_runner.run(seqs, is_prefill) → token_ids
            │     └── scheduler.postprocess(seqs, token_ids)
            │
            └── collect finished outputs
```

### 3.2 Scheduler

**职责**：管理序列的调度，实现 Continuous Batching。

```
┌─────────────────────────────────────────────────────────────────┐
│                          Scheduler                              │
├─────────────────────────────────────────────────────────────────┤
│  属性:                                                          │
│  ├── max_num_seqs: int            # 最大序列数                   │
│  ├── max_num_batched_tokens: int  # 最大批处理 tokens            │
│  ├── block_manager: BlockManager  # 块管理器                     │
│  ├── waiting: deque[Sequence]     # 等待队列                     │
│  └── running: deque[Sequence]     # 运行队列                     │
├─────────────────────────────────────────────────────────────────┤
│  方法:                                                          │
│  ├── add(seq)                     # 添加序列到等待队列           │
│  ├── schedule() → (seqs, is_prefill)  # 调度                     │
│  ├── preempt(seq)                 # 抢占序列                     │
│  ├── postprocess(seqs, token_ids) # 后处理                      │
│  └── is_finished()                # 检查是否完成                 │
└─────────────────────────────────────────────────────────────────┘
```

**调度策略**：

```
schedule() 执行流程
      │
      ├── PREFILL 阶段（优先）
      │     │
      │     └── while waiting 非空 and 未达限制:
      │           │
      │           ├── 检查资源: can_allocate(seq)
      │           ├── 分配块: block_manager.allocate(seq)
      │           ├── 更新状态: seq.status = RUNNING
      │           └── 移动到 running 队列
      │
      └── DECODE 阶段（无 prefill 时执行）
            │
            └── while running 非空 and 未达限制:
                  │
                  ├── 检查资源: can_append(seq)
                  │     └── 内存不足时抢占尾部序列
                  ├── 追加块: may_append(seq)
                  └── 收集到 scheduled_seqs
```

### 3.3 BlockManager

**职责**：管理 KV Cache 块，实现 Prefix Caching。

```
┌─────────────────────────────────────────────────────────────────┐
│                        BlockManager                             │
├─────────────────────────────────────────────────────────────────┤
│  属性:                                                          │
│  ├── block_size: int              # 块大小                       │
│  ├── blocks: list[Block]          # 所有块                       │
│  ├── hash_to_block_id: dict       # 哈希 → 块ID 映射             │
│  ├── free_block_ids: deque[int]   # 空闲块队列                   │
│  └── used_block_ids: set[int]     # 已使用块集合                 │
├─────────────────────────────────────────────────────────────────┤
│  方法:                                                          │
│  ├── compute_hash(token_ids, prefix)  # 计算块哈希               │
│  ├── can_allocate(seq)           # 检查是否可分配                │
│  ├── allocate(seq)               # 分配块（支持缓存命中）         │
│  ├── deallocate(seq)             # 释放块                        │
│  ├── can_append(seq)             # 检查是否可追加                 │
│  └── may_append(seq)             # 追加块                        │
└─────────────────────────────────────────────────────────────────┘
```

**Prefix Caching 流程**：

```
allocate(seq) 执行流程
      │
      └── for each block in seq:
            │
            ├── 计算哈希: h = compute_hash(token_ids, prefix_hash)
            │
            ├── 查找缓存: block_id = hash_to_block_id.get(h)
            │
            ├── if 缓存命中:
            │     ├── 复用块，增加引用计数
            │     └── 更新 num_cached_tokens
            │
            └── else 缓存未命中:
                  ├── 分配新块
                  └── 更新哈希映射
```

### 3.4 ModelRunner

**职责**：执行模型推理，管理 GPU 资源。

```
┌─────────────────────────────────────────────────────────────────┐
│                        ModelRunner                              │
├─────────────────────────────────────────────────────────────────┤
│  属性:                                                          │
│  ├── model: Qwen3ForCausalLM      # 模型                        │
│  ├── sampler: Sampler             # 采样器                       │
│  ├── kv_cache: Tensor             # KV Cache                     │
│  ├── graphs: dict[int, CUDAGraph] # CUDA Graph（按 batch size）  │
│  └── shm: SharedMemory            # 共享内存（张量并行）          │
├─────────────────────────────────────────────────────────────────┤
│  方法:                                                          │
│  ├── warmup_model()               # 预热模型                     │
│  ├── allocate_kv_cache()          # 分配 KV Cache                │
│  ├── prepare_prefill(seqs)        # 准备 prefill 数据            │
│  ├── prepare_decode(seqs)         # 准备 decode 数据             │
│  ├── run_model(...)               # 执行模型                     │
│  ├── run(seqs, is_prefill)        # 运行推理                     │
│  └── capture_cudagraph()          # 捕获 CUDA Graph              │
└─────────────────────────────────────────────────────────────────┘
```

**执行流程**：

```
run(seqs, is_prefill) 执行流程
      │
      ├── if is_prefill:
      │     └── prepare_prefill(seqs)
      │           ├── 收集 input_ids, positions
      │           ├── 计算 cu_seqlens_q, cu_seqlens_k
      │           ├── 计算 slot_mapping
      │           └── 设置 context
      │
      └── else (decode):
            └── prepare_decode(seqs)
                  ├── 收集 last_token 作为 input_ids
                  ├── 收集 positions
                  ├── 计算 slot_mapping
                  └── 设置 context
      │
      ├── run_model(input_ids, positions, is_prefill)
      │     │
      │     ├── if prefill or eager or large batch:
      │     │     └── model(input_ids, positions)
      │     │
      │     └── else (decode with CUDA Graph):
      │           ├── 选择合适的 graph
      │           ├── 更新 graph 变量
      │           └── graph.replay()
      │
      └── sampler(logits, temperatures) → token_ids
```

### 3.5 Sequence

**职责**：表示单个推理序列的状态。

```
┌─────────────────────────────────────────────────────────────────┐
│                          Sequence                               │
├─────────────────────────────────────────────────────────────────┤
│  属性:                                                          │
│  ├── seq_id: int                  # 序列 ID                      │
│  ├── status: SequenceStatus       # 状态                        │
│  ├── token_ids: list[int]         # 所有 tokens                  │
│  ├── num_prompt_tokens: int       # 输入 tokens 数               │
│  ├── num_cached_tokens: int       # 已缓存 tokens 数             │
│  ├── block_table: list[int]       # 块表                        │
│  ├── temperature: float           # 采样温度                     │
│  ├── max_tokens: int              # 最大生成长度                  │
│  └── ignore_eos: bool             # 忽略 EOS                     │
├─────────────────────────────────────────────────────────────────┤
│  计算属性:                                                       │
│  ├── num_blocks                   # 需要的块数                   │
│  ├── num_cached_blocks            # 已缓存的块数                 │
│  ├── prompt_token_ids             # 输入 tokens                  │
│  ├── completion_token_ids         # 生成的 tokens                │
│  └── last_block_num_tokens        # 最后一块的 token 数          │
├─────────────────────────────────────────────────────────────────┤
│  方法:                                                          │
│  ├── block(i)                     # 获取第 i 块的 tokens         │
│  └── append_token(token_id)       # 追加生成的 token             │
└─────────────────────────────────────────────────────────────────┘
```

## 7. CUDA Graph 设计

### 7.1 捕获策略

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         CUDA Graph 捕获策略                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  支持的 Batch Size: [1, 2, 4, 8, 16, 32, 48, 64, ..., 512]                  │
│                                                                             │
│  捕获流程:                                                                   │
│  1. 创建固定大小的输入缓冲区                                                 │
│  2. 对每个 batch size:                                                      │
│     a. 执行一次 warmup                                                      │
│     b. 使用 torch.cuda.graph 捕获                                          │
│     c. 共享 graph pool                                                      │
│                                                                             │
│  限制:                                                                       │
│  - 只用于 decode 阶段                                                       │
│  - 不用于 prefill 阶段                                                      │
│  - 不用于 batch > 512                                                       │
│  - 不用于 enforce_eager=True                                                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 7.2 执行流程

```
run_model() 中的 CUDA Graph 使用:

if is_prefill or enforce_eager or batch_size > 512:
    return model(input_ids, positions)  # Eager 模式
else:
    # 选择合适的 graph
    graph = graphs[next(bs for bs in graph_bs if bs >= batch_size)]
    
    # 更新输入缓冲区
    graph_vars["input_ids"][:batch_size] = input_ids
    graph_vars["positions"][:batch_size] = positions
    graph_vars["slot_mapping"][:batch_size] = slot_mapping
    graph_vars["context_lens"][:batch_size] = context_lens
    graph_vars["block_tables"][:batch_size] = block_tables
    
    # 回放 graph
    graph.replay()
    
    return graph_vars["outputs"][:batch_size]
```

## 9. 性能优化策略

### 9.1 优化技术总结

| 优化技术 | 作用 | 实现位置 |
|---------|------|---------|
| FlashAttention | 减少 HBM 访问 | `layers/attention.py` |
| Prefix Caching | 避免重复计算 | `engine/block_manager.py` |
| CUDA Graph | 减少 kernel 启动开销 | `engine/model_runner.py` |
| Torch Compile | 自动内核融合 | `layers/sampler.py`, `layers/layernorm.py` |
| Tensor Parallelism | 多 GPU 并行 | `layers/linear.py`, `layers/embed_head.py` |
| Continuous Batching | 提高吞吐量 | `engine/scheduler.py` |
| Pinned Memory | 加速 CPU-GPU 传输 | `engine/model_runner.py` |

### 9.2 优化效果

```
┌─────────────────────────────────────────────────────────────────────────────┐
```
